## 📌 Descripción del Proyecto

El proyecto consiste en documentar métodos formales para determinar distribuciones a priori y probar su comportamiento computacionalmente mediante **R**.

> **Condición obligatoria:** Los métodos a investigar deben ser **diferentes de la a priori no informativa de Jeffreys**.
